# Contributing to awesome-aec-mcp

Contributions welcome! This list is community-curated.

## How to add an entry

1. **Fork** this repository
2. **Add** your entry to the README.md in the appropriate section
3. **Submit** a Pull Request

## Entry format

```markdown
| [**project-name**](https://github.com/user/repo) | One-line description of what it does | ⭐ stars | Tech stack |
```

## Requirements

- The MCP server must be **open source**
- It must be **relevant to AEC** (Architecture, Engineering, Construction, GIS, or related 3D workflows)
- Include a **working link** to the repository
- Prefer servers that are **actively maintained**

## Quality guidelines

- One-line descriptions should be clear about what the tool does
- If the tool is your own, disclosure is appreciated but not required
- Screenshots or demo GIFs in the linked repo are a big plus

Thank you for helping build the AEC + AI ecosystem!
